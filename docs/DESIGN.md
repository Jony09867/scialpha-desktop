# UI/UX yo'nalishi

Asosiy rang #F65314, ikkinchi urg'u #0070C0; fon #F7F8FA, kartochka #FFFFFF, border #E2E5EC, sarlavha #F0F2F5.
Matn Inter, formulalar KaTeX, sonlar uchun monospace. Font yetkazish va litsenziya implementatsiyada tekshiriladi.

Yuqorida qidiruv, ilmiy belgilar va fan filtrlari. Keng oynada chap 45% talqin/natija/qadamlar/formulalar, o'ng 55% viewport/parametr/grafik.
Tor oynada ustunlar ketma-ket; sticky panel boshqa kontentni yopmaydi.
Bo'sh, loading, natija, unsupported, aniqlashtirish va xato holatlari alohida ko'zda tutiladi.

Slayderlar klaviaturadan boshqariladi va aniq sonli inputga ega.
Rangdan tashqari label/ikon/legend ishlatiladi. Harakatni pause qilish mumkin.
Formulalar va simulyatsiya uchun matnli talqin beriladi.
Tungi tema keyingi UI bosqichi; M1da yorug' tema ustuvor.
