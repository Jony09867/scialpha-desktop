# Mahsulot talablari

## Asosiy oqim

Foydalanuvchi preset tanlaydi yoki savol beradi. Ilova model talqini va farazlarni ko'rsatadi.
Tasdiqlangan parametrlar bilan hisoblanadi. Natija, formulalar, simulyatsiya va grafiklar yagona javob versiyasiga bog'lanadi.
Parametr o'zgarsa avvalgi so'rovning kech javobi yangi holatni bosib ketmasligi kerak.

## Funksional talablar

| ID | Talab | Bosqich |
| --- | --- | --- |
| FR01 | Qidiruv, fan filtri, ilmiy belgilar paneli | M1; tabiiy til M4 |
| FR02 | Talqin, natija, qadamlar va formulalar Pods | M1 |
| FR03 | 2D/3D, play/pause/reset, 0.25x/1x/2x, vektorlar | M1 |
| FR04 | Slayder + sonli kiritish + birlik + chegaralar | M1 |
| FR05 | Vaqtga bog'liq jonli grafik va legenda | M1 |
| FR06 | Snaryad, mayatnik, sirt/to'lqin, molekula va orbita | M1–M2 |
| FR07 | Tekshirilgan ilmiy backend | M3 |
| FR08 | O'zbek/ingliz/rus savollarini presetga moslash | M4 |
| FR09 | Windows installer va lokal yadro lifecycle | M5 |

Bir molekuladagi illustrativ thermal vibration ilmiy molekulyar dinamika sifatida belgilanmaydi.
Matematik sirtning 2D rejimi kesim bo'ladi; kimyoda strukturaviy chizma, astronomiyada orbital tekislik ko'rsatiladi.
Har bir savolga 3D sahna majburiy emas: qo'llanmaydigan holatda sabab tushuntiriladi.

## Hozirgi scope tashqarisida

Hisob yaratish/billing, bulut saqlash, mobil app, arbitrary code generation, biologiya simulyatsiyasining to'liq paketi.
Offline presetlar rejalashtirilgan; onlayn LLM rejimida tarmoq talab qilinishi ochiq ko'rsatiladi.
