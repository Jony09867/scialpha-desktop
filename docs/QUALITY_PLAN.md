# Tekshiruv rejasi

Bu fayl bajarilgan test hisoboti emas. Kod bo'lmagani uchun runtime/build testlari hali yo'q.

| Qatlam | Muhim tekshiruv |
| --- | --- |
| Ilmiy model | Referens formulalar, birliklar, chekka qiymatlar, invariant va tolerans |
| Kontrakt | Valid/invalid payload, versiya, noma'lum preset, NaN/Infinity, hajm limiti |
| State | 2D/3D almashish, pause/resume/reset, vaqt tezligi, parametr revisioni |
| Integratsiya | Parametrdan Pods/grafik/rendergacha; stale javob, cancel, backend uzilishi |
| UI | Klaviatura, oyna o'lchami, xatolar, formulalar va birliklar |
| LLM | Uch til misollari; noaniqlik, unsupported va prompt injection |
| Desktop | Toza Windows, offline preset, port konflikti, sidecar yopilishi, uninstall |
| Performance | Qurilma, GPU, dataset/sahna, FPS va input p95 qaydi |

Snaryad: GOALS referensi, nol tezlik, nol/noto'g'ri gravity, 0°/90° chegaralari va nonfinite kirishlar.
Mayatnik: kichik burchak davri va modelga mos energiya xatoligi.
Orbit: ikki jism farazi, massa/birlik va energiya/burchak momenti driftini kuzatish.
Molekula: atom soni, bog'lar va koordinata manbasi; illustrativ vibratsiya alohida label.
Sirt: ma'lum nuqtalar va kesimning 3D bilan mosligi.

Release uchun barcha bajarilgan mezonlar dalil bilan, bajarilmaganlari cheklov sifatida yoziladi.
